# Mejbahul Haq — Personal Portfolio Website

A professional personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive design (mobile, tablet, desktop)
- Animated particle network background
- Typewriter text animation
- Scroll reveal animations
- Dark mode toggle
- Education timeline
- Project showcase cards
- Contact section with social links
- SEO optimized

## Project Structure

```
├── index.html          ← Main website page
├── style.css           ← All styles and design
├── script.js           ← Animations and functionality
├── README.md           ← This file
├── .gitignore          ← Files to exclude from Git
└── assets/
    ├── images/         ← Profile photo, project images
    │   ├── profile.jpg
    │   ├── about.jpg
    │   └── esp32-relay.jpg
    └── documents/      ← Certificates and PDFs
```

## Quick Start

1. Open `index.html` in a web browser to preview.
2. Edit content using the Editing Guide below.
3. Add your images to the `assets/images/` folder.

## Deployment

This project is designed for **GitHub Pages**. See the Editing Guide for deployment instructions.
