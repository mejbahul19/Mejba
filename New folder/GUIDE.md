## ২. কোনো সেকশন যোগ (Add) বা ডিলিট (Delete) করলে সমস্যা কেন হয় এবং এর সমাধান কি?

### ❓ সমস্যা হওয়ার কারণ:
১. **HTML ট্যাগ বন্ধ না করা (Unclosed Tags):**
   - HTML-এ প্রতিটি ওপেনিং ট্যাগের যেমন `<section>`, `<div>` এর একটি ক্লোজিং ট্যাগ `</section>`, `</div>` থাকতে হয়।
   - কোনো সেকশন ডিলিট বা এডিট করতে গিয়ে যদি একটি `</div>` বা `</section>` মিস হয়ে যায় বা কমেন্টের ভেতরে পড়ে যায়, তবে তার নিচের সব সেকশন ওই সেকশনের ভেতরে ঢুকে যায়।
   - বিশেষ করে সার্টিফিকেট বা প্রজেক্ট সেকশনে CSS Grid (`display: grid`) ব্যবহার করা হয়। ট্যাগ বন্ধ না হলে পুরো কন্টাক্ট সেকশন ও ফুটার ৩০০০ পিক্সেলের বদলে একটি ছোট কার্ডের মতো সাইজে সংকুচিত হয়ে যায়।
২. **Navbar এর সাথে সেকশন ID না মেলা:**
   - উপরের মেনুতে থাকে `<a href="#certificates">Certificates</a>`।
   - আপনি যদি HTML থেকে `<section id="certificates">` মুছে দেন কিন্তু মেনু থেকে লিংক না মুছেন, তাহলে ক্লিক করলে পেজ ক্র্যাশ করতে পারে বা কাজ করবে না।

### ✅ সেকশন ডিলিট করার সঠিক নিয়ম:
যেকোনো সেকশন ডিলিট করতে চাইলে **২টি কাজ** করবেন:
1. **HTML ফাইল থেকে সেকশনটি শুরু থেকে শেষ পর্যন্ত মুছুন:**
   ```html
   <!-- এই পুরো ব্লকটি একসাথে মুছবেন -->
   <section class="section" id="section-id">
       <div class="container">
           ...
       </div>
   </section>
   ```
2. **উপরে Navbar মেনু থেকে লিংকটি মুছুন:**
   `index.html` ফাইলের `<nav class="nav-links">` অংশ থেকে ওই সেকশনের `<a>` ট্যাগটি মুছে দিন।

## ৩. শুধু কি `index.html` এ চেঞ্জ করলেই হয় নাকি সব ফাইলে করা লাগে?

| কাজের ধরন | কোন ফাইলে চেঞ্জ করবেন? | ব্যাখ্যা |
|---|---|---|
| **লেখা, ছবি, লিংক, সার্টিফিকেট বা প্রজেক্ট যোগ/ডিলিট করা** | **শুধু `index.html`** | বিদ্যমান ডিজাইন ও ক্লাসের নতুন কার্ড যোগ করলে শুধু HTML বদলালেই চলে। CSS বা JS ধরার দরকার নেই। |
| **বিদ্যমান কোনো সেকশন ডিলিট করা** | **শুধু `index.html`** | সেকশন কোড মুছবেন এবং মেনু লিংক মুছবেন। |
| **ওয়েবসাইটের রঙ / থিম বদলানো (যেমন: কমলা রঙ করা)** | **`style.css`** | CSS এর শুরুতে থাকা কালার ভ্যারিয়েবল পরিবর্তন করলেই পুরো ওয়েবসাইটে রঙ বদলে যায়। |
| **নতুন কোনো সম্পূর্ণ ভিন্ন ডিজাইন বা লেআউট তৈরি করা** | **`index.html` + `style.css`** | নতুন CSS ক্লাস লিখলে CSS ফাইলে যোগ করতে হয়। |
| **নতুন অ্যানিমেশন বা কোনো প্লাগইন যোগ করা** | **`script.js`** | সাধারণ এডিটের জন্য `script.js` এ হাত দেওয়ার প্রয়োজন নেই। |

> **সংক্ষেপে:** সাধারণ কন্টেন্ট বা সেকশন পরিবর্তন করতে **৯৮% সময় শুধু `index.html`** এডিট করলেই যথেষ্ট।

## ৪. থিম কালার কমলা (Orange) কীভাবে করবেন?

বর্তমানে ওয়েবসাইটের রঙ গ্রিন (Sage Green) ও গোল্ডেন অ্যাকসেন্ট। আপনি যদি সম্পূর্ণ সাইট **কমলা (Orange / Komla) থিম** করতে চান, তবে `style.css` ফাইলের ৫ থেকে ১৬ নম্বর লাইনে যান এবং নিচের কোডটি বসিয়ে দিন:

### `style.css` এডিট করুন:

```css
:root {
    /* 🍊 কমলা থিম (Orange Color Palette) */
    /* 🔥 Phyhunt (https://www.phyhunt.com/) কালার প্যালেট */
    --primary: #F86E49;          /* Phyhunt কোরাল অরেঞ্জ */
    --primary-light: #FF8F6E;    /* লাইট কোরাল অরেঞ্জ */
    --primary-dark: #D6492F;     /* ডিপ ক্রিমসন অরেঞ্জ */
    --primary-rgb: 248, 110, 73;

    --accent: #F64360;           /* Phyhunt সিগনেচার রোজ কোরাল */
    --accent-light: #FFA1B2;     /* লাইট রোজ পিঙ্ক */
    --accent-rgb: 246, 67, 96;

    --phyhunt-magenta: #F4137B;  /* Phyhunt এক্সেন্ট ম্যাজেন্টা */
```

> **টিপস:** `script.js` ফাইলে ব্যাকগ্রাউন্ডের পার্টিক্যালগুলো এখন স্বয়ংক্রিয়ভাবে CSS এর `--accent` রঙ গ্রহণ করে। তাই `style.css` এ রঙ বদলালেই পার্টিক্যালের রঙও নিজ থেকেই কমলা হয়ে যাবে!

## ৫. নতুন সার্টিফিকেট যোগ করার প্রস্তুত কোড (Copy-Paste Template)

ভবিষ্যতে নতুন সার্টিফিকেট যোগ করতে চাইলে `index.html` এর `<div class="certificates-grid">` এর ভেতরে নিচের কোডটি কপি করে পেস্ট করবেন:

```html
<div class="certificate-card reveal">
    <div class="cert-icon">
        <i class="fas fa-award"></i>
    </div>
    <div class="cert-info">
        <h4>সার্টিফিকেটের নাম এখানে দিন</h4>
        <p>প্রতিষ্ঠান বা অর্গানাইজেশন — সাল</p>
        <a href="assets/আপনার-সার্টিফিকেট-ফাইল.pdf" target="_blank" class="cert-link">
            <i class="fas fa-external-link-alt"></i> View Certificate
        </a>
    </div>
    <div class="cert-badge">
        <i class="fas fa-check-circle"></i>
    </div>
</div>
```
